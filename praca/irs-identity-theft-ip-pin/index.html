IRS identity theft i IP PIN — jak chronić tax return?

Ktoś złożył return z Twoim SSN? Dostałeś podejrzany SMS „od IRS”? Wyjaśniamy IP PIN, tax-related identity theft, Form 14039 i bezpieczne kroki po kradzieży danych.

Sprawdzono: 25 września 2026

Najkrócej: jak chronić tax return przed kradzieżą tożsamości?

Najmocniejszym prostym zabezpieczeniem oferowanym przez IRS jest IP PIN — sześciocyfrowy numer, który pomaga zablokować złożenie federalnego tax return przy użyciu Twojego SSN lub ITIN przez inną osobę. Każdy, kto ma SSN lub ITIN i potrafi zweryfikować swoją tożsamość, może dobrowolnie przystąpić do programu.

Najważniejsze w 30 sekund

  • IP PIN ma 6 cyfr i jest znany tylko Tobie oraz IRS.
  • Nowy IP PIN jest generowany na każdy rok kalendarzowy.
  • Nie udostępniaj go nikomu poza zaufanym tax preparerem, gdy przygotowuje return.
  • IRS nie zadzwoni, nie napisze emaila ani SMS-a z prośbą o podanie IP PIN.
  • Jeśli e-file zostaje odrzucony, bo ktoś już użył Twojego SSN/ITIN, może chodzić o tax-related identity theft.
  • Phishing, smishing i fałszywe „refunds” są częstymi sposobami wyłudzania danych.

Co to jest tax-related identity theft?

Dochodzi do niego m.in. wtedy, gdy ktoś wykorzystuje skradzione SSN lub ITIN do złożenia fałszywego tax return i próby przejęcia refund. IRS ostrzega, że przestępcy wykorzystują phishing, smishing i fałszywe porady podatkowe do zdobywania danych osobowych.

IP PIN — jak działa?

Identity Protection PIN jest sześciocyfrowym numerem weryfikującym, że osoba składająca federalny return jest właścicielem używanego SSN lub ITIN. IRS generuje nowy numer każdego roku. Jeśli masz aktywny IP PIN, prawidłowy numer trzeba podać przy odpowiednich federal returns składanych w danym roku.

Kto może dostać IP PIN?

Program nie jest ograniczony do osób, które już padły ofiarą identity theft. IRS pozwala dobrowolnie uzyskać IP PIN każdej osobie z SSN lub ITIN, która przejdzie identity verification. Rodzic lub legal guardian może również wystąpić o IP PIN dla dependent.

Jak dostać IP PIN?

Najszybszą metodą jest IRS Online Account. Po zweryfikowaniu tożsamości aktualny IP PIN można znaleźć w profilu konta. IRS publikuje również alternatywne procedury dla osób, które nie mogą skorzystać z procesu online.

Nigdy nie podawaj IP PIN osobie dzwoniącej „z IRS”

IRS wyraźnie informuje, że nie prosi podatników o IP PIN przez telefon, email ani SMS. Numer przekazuj wyłącznie zaufanemu tax professional, kiedy przygotowuje i składa Twój return.

Co jeśli return zostaje odrzucony jako już złożony?

Jeżeli nie składałeś return, a system wskazuje, że return z Twoim SSN lub ITIN już istnieje, postępuj według instrukcji IRS dotyczących identity theft. IRS może wymagać weryfikacji tożsamości albo Form 14039, Identity Theft Affidavit, zależnie od sytuacji.

Form 14039

Form 14039 służy do zgłoszenia określonych przypadków tax-related identity theft. Nie należy wysyłać go automatycznie przy każdym podejrzanym zdarzeniu — jeśli IRS wysłał Ci notice dotyczący identity verification, wykonaj instrukcje z konkretnego pisma. IRS wskazuje, że po pomyślnej weryfikacji return Form 14039 może nie być potrzebny, chyba że urząd o niego poprosi.

Jak rozpoznać fałszywy kontakt z IRS?

Typowe sygnały ostrzegawcze to nieoczekiwany kontakt, presja na natychmiastową płatność, groźby arrest/deportation, obietnica dużego refund lub credit, prośba o dane finansowe oraz podejrzany link. IRS ostrzega również przed fałszywymi social-media accounts i wiadomościami o rzekomych credits lub stimulus payments.

Email i SMS „od IRS”

IRS nie inicjuje kontaktu z podatnikiem przez email lub social media w celu uzyskania personal lub financial information. Podejrzanych linków i attachments nie otwieraj. Fałszywe wiadomości IRS/Treasury można zgłaszać zgodnie z instrukcją IRS.

Fałszywe porady podatkowe w social media

IRS ostrzega również przed postami obiecującymi „sekretne” credits, ogromne refunds lub zachęcającymi do wpisywania fikcyjnych income/withholding. Podatnik odpowiada za return podpisany i wysłany w jego imieniu, nawet jeśli zła porada pochodziła od influencera lub preparera.

Co zrobić, jeśli podałeś scammerowi dane?

  1. Przerwij kontakt i nie wysyłaj kolejnych pieniędzy ani informacji.
  2. Jeśli podałeś dane finansowe, skontaktuj się z bankiem lub inną financial institution.
  3. Postępuj według procedur IdentityTheft.gov oraz IRS dla tax-related identity theft.
  4. Rozważ uzyskanie IP PIN.
  5. Załóż lub sprawdź IRS Online Account i monitoruj aktywność.
  6. Jeśli otrzymałeś IRS notice, zweryfikuj go oficjalnym kanałem i wykonaj instrukcje.

IRS zaleca takie działania osobom, których pieniądze lub dane zostały skradzione.

Ważne
