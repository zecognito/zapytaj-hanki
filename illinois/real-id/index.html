REAL ID w Illinois — dokumenty, nazwisko i procedura

REAL ID wygląda podobnie do zwykłego prawa jazdy lub State ID, ale spełnia federalne wymagania identyfikacyjne. Najczęstszą przyczyną nieudanej wizyty jest brak drugiego, prawidłowego dowodu adresu.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

Aby otrzymać REAL ID w Illinois, zbierz dokument potwierdzający tożsamość i legalny status, dokument z pełnym numerem Social Security, dwa dokumenty potwierdzające adres w Illinois oraz dokument z podpisem. Następnie złóż wniosek osobiście w pełnowymiarowej placówce DMV. Po wizycie dostaniesz dokument tymczasowy, a stała karta powinna przyjść pocztą w ciągu 15 dni roboczych.

Lista kontrolna

  • 1 dokument: tożsamość, data urodzenia i citizenship/lawful status.
  • 1 dokument: pełny numer Social Security.
  • 2 różne dokumenty: aktualny adres w Illinois.
  • 1 dokument: podpis.
  • Dokument łączący nazwiska, jeśli nazwisko się zmieniło.
  • Wizyta w odpowiedniej placówce DMV.

Czy naprawdę potrzebujesz REAL ID?

REAL ID nie jest obowiązkowe do prowadzenia samochodu. Zwykłe prawo jazdy Illinois nadal potwierdza uprawnienia do jazdy. REAL ID jest potrzebne, gdy chcesz używać stanowego prawa jazdy lub State ID do celów federalnych, m.in. przy kontroli bezpieczeństwa przed lotem krajowym albo przy wejściu do niektórych obiektów federalnych.

Jeżeli masz ważny paszport USA, kartę paszportową albo inny dokument akceptowany przez TSA, możesz używać go zamiast REAL ID podczas podróży lotniczej. REAL ID nie zastępuje paszportu podczas podróży międzynarodowej.

Jeśli masz ważne prawo jazdy lub State ID z Illinois i urząd wcześniej zweryfikował twój Social Security number, oddzielny dokument z SSN może nie być ponownie wymagany. Skorzystaj jednak z oficjalnej checklisty dla własnej sytuacji przed wizytą.

Dwa dowody adresu oznaczają dwa dokumenty

Oba dokumenty muszą pokazywać twoje pełne imię i nazwisko oraz aktualny adres zamieszkania w Illinois. Wiele akceptowanych dokumentów musi być wystawionych w określonym okresie, często w ciągu 90 dni przed wnioskiem. Wydrukowany elektroniczny bank statement lub utility bill może być akceptowany, jeżeli spełnia wymagania i pokazuje wymagane dane.

Sprawdź zgodność nazwiska

Jeżeli nazwisko na akcie urodzenia lub paszporcie różni się od obecnego nazwiska, potrzebujesz dokumentu tworzącego pełne połączenie między nazwiskami — np. poświadczonego aktu małżeństwa, dokumentu adopcji albo sądowego dokumentu zmiany nazwiska. Przy kilku zmianach nazwiska może być potrzebny cały łańcuch dokumentów.

Oryginały, kopie i wydruki

Dokumenty muszą być ważne i aktualne. Illinois Secretary of State informuje, że zwykłe kserokopie nie są akceptowane. Dokumenty elektroniczne potwierdzające adres można wydrukować; numery kont muszą pozostać widoczne. Akt urodzenia lub akt małżeństwa powinien być oryginałem albo urzędowo poświadczoną kopią wydaną przez właściwy urząd, a nie zwykłą kopią wykonaną samodzielnie.

Proces krok po kroku

  1. Otwórz oficjalną checklistę REAL ID i wybierz dokładne dokumenty.
  2. Sprawdź, czy wszystkie nazwiska, daty i adresy są zgodne.
  3. Znajdź pełnowymiarową placówkę DMV obsługującą REAL ID i sprawdź, czy wymaga rezerwacji.
  4. Zabierz komplet dokumentów i złóż wniosek osobiście.
  5. Po zaakceptowaniu wniosku odbierz tymczasowe papierowe prawo jazdy lub State ID.
  6. Poczekaj na stałą kartę wysłaną pocztą; urząd podaje do 15 dni roboczych.

Czy tymczasowy dokument działa na lotnisku?

Papierowy dokument wydany po złożeniu wniosku nie jest tym samym co stała karta REAL ID. Jeżeli planujesz lot, nie zakładaj, że tymczasowy wydruk zostanie zaakceptowany jako REAL ID. Zabierz ważny paszport lub inny dokument z aktualnej listy TSA i zaplanuj wniosek z odpowiednim wyprzedzeniem.

Ile kosztuje REAL ID?

Illinois nie przedstawia REAL ID jako osobnej dodatkowej opłaty ponad opłatę za wydanie lub odnowienie odpowiedniego prawa jazdy albo State ID. Ostateczny koszt zależy więc od rodzaju transakcji, wieku i tego, czy dokument jest nowy, odnawiany, poprawiany lub duplikowany. Przed wizytą sprawdź aktualną tabelę Driver Services Fees.

REAL ID z innego stanu

REAL ID wydane przez inny stan nie „przenosi się” automatycznie do Illinois. Nowy mieszkaniec składa wniosek o dokument Illinois i ponownie przedstawia wymagane dokumenty, w tym dwa dowody nowego adresu w Illinois.

Najczęstsze błędy

  • Tylko jeden dowód adresu zamiast dwóch.
  • Dokument adresowy jest zbyt stary albo zawiera inny adres.
  • W-2 lub pay stub nie pokazuje pełnego SSN.
  • Zwykła kserokopia aktu urodzenia lub małżeństwa.
  • Brak dokumentu łączącego poprzednie i obecne nazwisko.
  • Założenie, że tymczasowy papierowy dokument wystarczy do lotu.

Przykład: inne nazwisko na dokumentach

Jeśli dokument tożsamości ma inne nazwisko niż pozostałe zaświadczenia, sprawdź wcześniej, czy potrzebujesz dokumentu łączącego nazwiska, np. aktu małżeństwa lub decyzji o zmianie nazwiska. Nie zakładaj, że sama karta z aktualnym nazwiskiem rozwiąże każdą rozbieżność.

REAL ID czy paszport na lot krajowy?

REAL ID to jedna z akceptowanych form identyfikacji przy kontroli TSA, ale nie jedyna. Jeżeli masz inny dokument akceptowany przez TSA, sprawdź aktualną listę przed planowaną podróżą. Tymczasowe dokumenty wydawane podczas wizyty mogą nie spełniać wymogów kontroli lotniskowej.
