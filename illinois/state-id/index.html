State ID w Illinois — jak uzyskać stanowy dokument tożsamości

State ID jest dokumentem ze zdjęciem dla osoby, która potrzebuje oficjalnego ID, ale nie prawa jazdy. Nie daje uprawnień do prowadzenia samochodu.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

O pierwsze Illinois State ID składasz wniosek osobiście w placówce DMV. Przy standardowym ID przygotuj po jednym dokumencie potwierdzającym podpis, datę urodzenia, numer Social Security i adres w Illinois. Nie zdajesz testu pisemnego ani drogowego. Standardowe pięcioletnie ID kosztuje obecnie $20 dla osób w wieku 18–64 lat i $5 dla osób poniżej 18 lat. Osoby od 65. roku życia mogą otrzymać bezpłatne, bezterminowe State ID.

Najważniejsze informacje

  • State ID potwierdza tożsamość, ale nie pozwala prowadzić samochodu.
  • Pierwszy wniosek wymaga wizyty w DMV i dokumentów z grup A–D.
  • Możesz wybrać wersję standardową albo REAL ID.
  • Stała karta jest wysyłana pocztą; wcześniej otrzymasz dokument tymczasowy.
  • Seniorzy 65+, osoby z niepełnosprawnościami i niektóre inne grupy mogą kwalifikować się do bezpłatnego ID.

Dla kogo jest State ID?

State ID przydaje się jako oficjalny dokument ze zdjęciem przy załatwianiu spraw bankowych, medycznych, mieszkaniowych, urzędowych i wielu codziennych formalności. Jest odpowiednie dla osoby, która nie prowadzi samochodu, nie może prowadzić albo po prostu nie potrzebuje prawa jazdy.

State ID to nie prawo jazdy

Karta może wyglądać podobnie do prawa jazdy, ale nie daje żadnych uprawnień do kierowania pojazdem. Do prowadzenia samochodu potrzebne jest ważne driver’s license odpowiedniej klasy.

Jakie dokumenty przygotować?

Przy pierwszym standardowym State ID Illinois wymaga po jednym dokumencie z każdej grupy A, B, C i D. Dokumenty muszą być ważne i zgodne z oficjalną listą.

GrupaCo potwierdzaPrzykłady
APodpisKarta płatnicza, paszport, Social Security card lub aktualne ID
BData urodzeniaAkt urodzenia, paszport, dokument naturalizacji lub wybrany dokument USCIS
CSocial Security numberSocial Security card, W-2, SSA-1099 lub pay stub z pełnym SSN
DAdres w IllinoisBank statement, lease, utility bill, polisa mieszkaniowa lub korespondencja urzędowa

Jeden dokument może czasem spełniać więcej niż jedną grupę. Zwykłe zdjęcia dokumentów w telefonie i niepoświadczone kserokopie nie są akceptowane. Dokument elektroniczny potwierdzający adres można wydrukować, jeżeli spełnia wymagania urzędu.

Standardowe State ID czy REAL ID?

Standardowa karta wystarcza do większości spraw stanowych i codziennej identyfikacji. Wersja REAL ID spełnia dodatkowe wymogi federalne i może służyć przy kontroli bezpieczeństwa przed lotem krajowym lub wejściu do niektórych obiektów federalnych.

Pierwszy REAL ID wymaga dwóch dokumentów potwierdzających adres w Illinois, a także dowodów tożsamości, lawful status, Social Security number i podpisu. Jeśli masz ważny paszport albo inny dokument akceptowany przez TSA, nie musisz wybierać REAL ID tylko ze względu na podróż lotniczą.

Opłaty mogą się zmienić. Niektóre duplikaty lub korekty są bezpłatne w szczególnych sytuacjach, np. dla części seniorów, członków sił zbrojnych albo przy kradzieży udokumentowanej raportem policyjnym.

Kto może otrzymać bezpłatne ID?

Osoby od 65. roku życia

Illinois oferuje osobom w wieku 65 lat lub starszym bezpłatne State ID bez daty wygaśnięcia.

Osoby z niepełnosprawnościami

Person with Disabilities Identification Card jest bezpłatna, ale wymaga odpowiedniego formularza wypełnionego przez lekarza przed wizytą w DMV.

Osoby doświadczające bezdomności

Osoba spełniająca definicję bezdomności może kwalifikować się do bezpłatnej karty po przedstawieniu wymaganych dokumentów i Homeless Status Certification.

Youth in Care

Osoby w wieku 16–20 lat pozostające pod opieką Illinois Department of Children and Family Services mogą kwalifikować się do bezpłatnego ID z aktualnym Form 906.

Proces krok po kroku

  1. Zdecyduj, czy chcesz standardowe State ID, czy REAL ID.
  2. Skorzystaj z oficjalnej checklisty i przygotuj właściwe dokumenty.
  3. Znajdź placówkę DMV obsługującą pierwsze wydanie State ID i sprawdź, czy wymaga appointment.
  4. Złóż wniosek osobiście, pokaż dokumenty, zrób zdjęcie i zapłać właściwą opłatę.
  5. Odbierz tymczasowy papierowy dokument.
  6. Stała karta powinna przyjść pocztą w ciągu 15 dni roboczych.

Co jeśli nie możesz pojechać do DMV?

Illinois prowadzi Homebound State ID Card Program dla starszych osób, osób obłożnie chorych i osób z niepełnosprawnościami, które nie mogą opuścić domu, aby uzyskać dokument w DMV. Program wymaga osobnego kontaktu i kwalifikacji; nie jest zwykłą usługą online.

Zgubione, skradzione lub uszkodzone ID

Wiele osób może zamówić duplicate ID online, ale istnieją wyjątki. Wizyta może być konieczna m.in. przy zmianie danych, określonych typach bezpłatnych kart, niedawnej zmianie adresu albo po przekroczeniu limitu wcześniejszych duplikatów. Jeśli dokument został skradziony, raport policyjny może mieć znaczenie dla zwolnienia z opłaty.

Najczęstsze problemy

  • Dokument adresowy nie pokazuje pełnego nazwiska i adresu.
  • Dokument jest zbyt stary albo nie znajduje się na oficjalnej liście.
  • Wnioskodawca przynosi zdjęcie dokumentu zamiast wymaganego oryginału lub wydruku.
  • Nazwiska na dokumentach różnią się i brakuje dokumentu łączącego zmianę.
  • Osoba wybiera REAL ID, ale przynosi tylko jeden dowód adresu.

Praktyczny przykład: dokument tożsamości bez prawa jazdy

Jeżeli nie prowadzisz samochodu, Illinois State ID może służyć do potwierdzania tożsamości. Przed wizytą sprawdź oficjalną listę dokumentów i wybierz standardowe ID albo REAL ID zależnie od potrzeb. State ID nie daje uprawnień do kierowania pojazdem.

Lista kontrolna przed wizytą

Sprawdź aktualne wymagania Illinois Secretary of State, dostępność placówki i zgodność nazwiska na dokumentach. Jeśli brakuje potwierdzenia adresu, zapoznaj się z oficjalnymi opcjami zamiast zakładać, że każdy dokument zostanie przyjęty.
