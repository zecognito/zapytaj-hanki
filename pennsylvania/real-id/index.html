REAL ID w Pensylwanii — dokumenty, koszt i proces

Kiedy potrzebujesz REAL ID, jakie dokumenty przygotować, ile kosztuje, jak działa pre-verification i gdzie można otrzymać Pennsylvania REAL ID.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

REAL ID jest w Pensylwanii opcjonalny, ale od 7 maja 2025 do określonych celów federalnych, m.in. wejścia na pokład krajowego lotu bez innego akceptowanego dokumentu, potrzebujesz REAL ID albo innego dokumentu akceptowanego federalnie. Pierwszy REAL ID kosztuje jednorazowo $30 plus właściwa opłata za license/ID.

Najważniejsze informacje

  • REAL ID nie jest obowiązkowy do prowadzenia auta ani do zwykłego funkcjonowania w Pensylwanii.
  • Potrzebujesz 1 proof of identity/lawful status, 1 proof of Social Security number i 2 proofs of Pennsylvania residency.
  • Dokumenty muszą spełniać wymagania PennDOT; oryginały lub certified copies są kluczowe przy pierwszej weryfikacji.
  • Jednorazowa opłata REAL ID wynosi $30 plus standardowa opłata za właściwy produkt.
  • Same-Day REAL ID Centers mogą wydać dokument tego samego dnia; zwykły Driver License Center wysyła go pocztą po weryfikacji.

Czy potrzebujesz REAL ID?

Nie każdy go potrzebuje. Standardowe Pennsylvania driver’s license lub Photo ID nadal mogą służyć do wielu stanowych i codziennych celów. Do federalnych zastosowań objętych REAL ID możesz zamiast REAL ID użyć innego akceptowanego dokumentu, np. ważnego paszportu.

Jakie dokumenty są wymagane?

PennDOT wymaga dokumentu potwierdzającego identity and lawful status, dokumentu potwierdzającego Social Security number oraz dwóch dokumentów potwierdzających adres w Pensylwanii. Przykładowe dowody adresu to PA vehicle registration, auto insurance card, utility bill, W-2/pay stub, tax records, lease lub mortgage document. Przy zmianach nazwiska mogą być potrzebne dokumenty łączące kolejne nazwiska.

Osoby niebędące obywatelami USA

Lawfully present non-U.S. citizens mogą ubiegać się o REAL ID, ale wymagania dotyczące dokumentów imigracyjnych zależą od statusu. PennDOT publikuje oddzielną checklistę. Przy statusie czasowym data ważności REAL ID może być powiązana z datą ważności dokumentacji imigracyjnej.

Gdzie i jak złożyć wniosek?

Jeżeli PennDOT ma już zweryfikowane dokumenty — co może dotyczyć części osób, które pierwszy PA license, permit lub Photo ID otrzymały po wrześniu 2003 — możesz kwalifikować się do pre-verification i zamówienia REAL ID online. W przeciwnym razie dokumenty są sprawdzane osobiście. Same-Day REAL ID Center może wydać dokument na miejscu; po złożeniu w zwykłym Driver License Center PennDOT podaje wysyłkę w ciągu 15 business days.

Ile kosztuje REAL ID?

Jednorazowa opłata REAL ID wynosi $30. Do tego dochodzi odpowiednia standardowa opłata za renewal/produkt. PennDOT podaje przykład: REAL ID przy odnowieniu czteroletniego non-commercial driver’s license kosztuje łącznie $69.50 ($30 + $39.50).

Nie czekaj do dnia lotu

Jeżeli planujesz używać REAL ID do podróży, załatw dokument wcześniej. Dostępność same-day service zależy od rodzaju placówki, a nie każdy wniosek można zakończyć online.
