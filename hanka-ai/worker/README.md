# Hanka AI Worker

Private beta backend for Hanka AI.

- Cloudflare Worker: `hanka-ai-beta`
- Workers AI binding: `AI`
- Model is configured through `HANKA_MODEL`
- Endpoints: `GET /health`, `POST /chat`

This Worker is developed on `feature/hanka-ai` and is not part of the live `main` branch until explicitly approved.
