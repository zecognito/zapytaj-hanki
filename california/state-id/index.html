California ID Card — dokumenty, opłaty i wniosek

Jak uzyskać stanowy dokument tożsamości w Kalifornii: wymagane dokumenty, standard ID, REAL ID, senior ID oraz reduced-fee ID.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

California ID Card jest dokumentem ze zdjęciem dla osoby, która potrzebuje oficjalnego ID, ale nie prawa jazdy. Regularna karta kosztuje obecnie $40. Senior Citizen ID dla osób w wieku 62+ jest bezpłatna, a reduced-fee ID kosztuje $11 dla osób spełniających wymagania programu.

Najważniejsze informacje

  • ID Card nie daje uprawnień do prowadzenia samochodu.
  • Regularna California ID Card kosztuje obecnie $40.
  • Senior Citizen ID dla osób 62+ jest bezpłatna.
  • Reduced-fee ID kosztuje obecnie $11 dla kwalifikujących się osób.
  • Możesz wybrać standard ID albo REAL ID, jeśli spełniasz wymagania.

Dla kogo jest California ID Card?

To stanowy dokument tożsamości ze zdjęciem dla osób, które nie potrzebują driver’s license.

ID Card to nie prawo jazdy

California ID Card nie daje żadnych uprawnień do kierowania pojazdem.

Jakie dokumenty przygotować?

Dokładny zestaw zależy od tego, czy wybierasz standard ID czy REAL ID. Przy pierwszym wniosku przygotuj dokumenty tożsamości i California residency zgodne z aktualną checklistą DMV.

Ile kosztuje?

RodzajAktualna opłata
Regular ID Card$40
Reduced-fee ID Card$11
Senior Citizen ID Card, 62+$0

Standard ID czy REAL ID?

REAL ID spełnia dodatkowe wymogi federalne i wymaga szerszego zestawu dokumentów.

Proces krok po kroku

  1. Wybierz standard ID albo REAL ID.
  2. Wypełnij aplikację.
  3. Przygotuj dokumenty.
  4. Odwiedź DMV i wykonaj zdjęcie.
  5. Zapłać właściwą opłatę.
